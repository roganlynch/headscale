## Workstream A: Node session-expiry controls

Server already supports this fully via `POST /api/v1/node/{nodeId}/expire` (`hscontrol/api/v1/nodes.go:279`), which accepts an optional body `{expiry?: RFC3339 string, disableExpiry?: bool}` — omitted/empty body expires the node **now**; `expiry` set expires it at that time; `disableExpiry: true` makes it never expire. The response is the updated `Node`, which also carries an `expiry` field (`hscontrol/api/v1/nodes.go:46`) that `headscale-ui`'s `Device` class currently doesn't even capture. None of this is exposed today — `DeviceCard.svelte` has rename/move/remove/tags/routes but nothing for expiry.

### Task A2: Add `expireNode` API function

**Files:**

**Interfaces:**

- [ ] **Step 1: Add the function**

Add this function to `src/lib/common/apiFunctions.svelte`, next to `removeDevice` (matching its structure exactly — POST with a body, same header/error pattern as `moveDevice`):

```ts
export async function expireNode(deviceID: string, options?: { expiry?: string; disableExpiry?: boolean }): Promise<any> {

	// variables in local storage
	let headscaleURL = localStorage.getItem('headscaleURL') || '';
	let headscaleAPIKey = localStorage.getItem('headscaleAPIKey') || '';

	// endpoint url for expiring a node's session
	let endpointURL = `/api/v1/node/${deviceID}/expire`;

	let body: { expiry?: string; disableExpiry?: boolean } = {};
	if (options?.disableExpiry) {
		body.disableExpiry = true;
	} else if (options?.expiry) {
		body.expiry = options.expiry;
	}

	await fetch(headscaleURL + endpointURL, {
		method: 'POST',
		headers: {
			Accept: 'application/json',
			'Content-Type': 'application/json',
			Authorization: `Bearer ${headscaleAPIKey}`
		},
		body: JSON.stringify(body)
	})
		.then((response) => {
			if (response.ok) {
				return response;
			} else {
				return response.text().then((text) => {
					throw JSON.parse(text).message;
				});
			}
		})
		.catch((error) => {
			throw error;
		});
}
```

Note: unlike every other POST in this file, the server's `ExpireNodeRequestBody` is genuinely optional (`hscontrol/api/v1/nodes.go:129`, `required:"false"`) and rejects a body that sets both `expiry` and `disableExpiry` with a 400 (`hscontrol/api/v1/nodes.go:301`) — the `else if` above enforces that only one is ever sent. Also note this is the first POST body in the file to need an explicit `Content-Type: application/json` header; the existing functions omit it because their bodies happen to still parse, but add it here for correctness since huma is stricter about body-optional operations.

```ts
	let headscaleURL = localStorage.getItem('headscaleURL') || '';
	let headscaleAPIKey = localStorage.getItem('headscaleAPIKey') || '';

	let endpointURL = '/api/v1/policy';
	let response: Response = new Response();

	await fetch(headscaleURL + endpointURL, {
		method: 'GET',
		headers: {
			Accept: 'application/json',
			Authorization: `Bearer ${headscaleAPIKey}`
		}
	})

			if (res.ok) {

					throw JSON.parse(text).message;
```

```svelte
<script lang="ts">

	import { fade } from 'svelte/transition';
	import { getPolicy, setPolicy, checkPolicy } from '$lib/common/apiFunctions.svelte';
	import { alertStore } from '$lib/common/stores';

	let policyText = '';
	let updatedAt = '';
	let loaded = false;
	let checking = false;
	let saving = false;
	let checkResult: 'idle' | 'ok' | 'failed' = 'idle';

		getPolicy()
			.then((data) => {
				policyText = data.policy;
				updatedAt = data.updatedAt;
				loaded = true;

			.catch((error) => {

				checkResult = 'failed';
				$alertStore = error;
			})
			.finally(() => {
				saving = false;
			});
```

## Workstream C: Pending auth-request approval queue

```go
// AuthCacheEntry pairs a pending auth request with the ID it is stored
// under — the underlying LRU only hands back keys and values separately.
type AuthCacheEntry struct {
	ID      types.AuthID
	Request *types.AuthRequest
}

// ListAuthCacheEntries returns a snapshot of all pending auth requests.
// It uses Peek rather than Get so listing does not disturb the cache's
// LRU recency or its TTL-based eviction.
func (s *State) ListAuthCacheEntries() []AuthCacheEntry {
	keys := s.authCache.Keys()
	entries := make([]AuthCacheEntry, 0, len(keys))

	for _, id := range keys {
		if req, ok := s.authCache.Peek(id); ok {
			entries = append(entries, AuthCacheEntry{ID: id, Request: req})
		}
	}

	return entries
}
```
